# Dial

An espresso dial-in tool for a Baratza Encore ESP grinder and a Breville Bambino machine.

Everything is in a single file, `index.html`, written in Claude artifact format, so the `<!doctype>`, `<html>` and `<body>` wrappers are added when the page is published. Beans, shots and settings are saved in the browser's localStorage under the key `dial.v1`.

Live version: https://claude.ai/artifact/XzfPxjFuQttqarGxw6UJs1
